- Uli mentioned that both the Pi 5 and the Pi Zero 2 W are currently out of stock, we probaly have to 
use an alternative. We have to design our Software that it could run on other single board computers.

- When presenting things that we need like hardware we should start with the "why". For example why do we need a Pi 5: Because it has enough computing power for our image recognition.

- We have selected some common protocols for our communication (MQTT, RTSP, …); we should check whether there are other protocols for our use cases that are already in use in the drone industry. Team 1 mentioned MavLink and pointed out that there are already some solutions for video transmission (TBS Unify Pro32 HV FPV video transmitter MMCX).

- We need to define some basic requirements for our single-board computer, which will handle image recognition, and pass these requirements on to Team 1. In doing so, we should consider the following:
  - Battery consumption
  - Computing power (A more powerful computer means more weight for the drone)

  Perhaps we can create a document in which we specify, for example, that we can recognize objects with a certain level of battery consumption and computing power, and that we’ll need more battery life or computing power if we want to recognize more objects or do so more reliably.
